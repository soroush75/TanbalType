# فایل نصبی TanbalType (InstallShield)

<div align="right" dir="rtl">

پروژهٔ InstallShield برای ساختن `TanbalType-1.5.0-setup.exe`.

## ساختن فایل نصبی

```bat
installer\build-installer.bat
```

خروجی:

```
installer\TanbalType\TanbalType\SingleImage\DiskImages\DISK1\TanbalType-1.5.0-setup.exe
```

این اسکریپت سه کار می‌کند: برنامه را publish می‌کند، پروژهٔ `.ism` را می‌سازد و با
`IsCmdBld.exe` بیلد می‌گیرد. نیازی به دسترسی ادمین ندارد.

### نسخهٔ آفلاین

به‌صورت پیش‌فرض اگر .NET 8 روی سیستم کاربر نباشد، نصب‌کننده آن را از سایت مایکروسافت
دانلود می‌کند و حجم `setup.exe` حدود ۳٫۵ مگابایت می‌ماند. اگر می‌خواهید فایل نصبی
بدون اینترنت هم کار کند (مثلاً برای توزیع داخلی)، خودِ .NET 8 داخل `setup.exe`
بسته‌بندی می‌شود:

```bat
installer\build-installer.bat offline
```

حجم خروجی به حدود ۶۲ مگابایت می‌رسد. بار اول باید اینترنت داشته باشید: اسکریپت
فایل redistributable را در `installer\prereq\` می‌گیرد، درستی‌اش را با
checksumِ خودِ `.prq` می‌سنجد و از همان‌جا داخل `setup.exe` بسته‌بندی می‌کند. این
پوشه در `.gitignore` است، پس بارهای بعد دوباره دانلود نمی‌شود. (گزینهٔ
`-prqdownload` خودِ InstallShield استفاده نمی‌شود، چون داخل Program Files
می‌نویسد و ادمین می‌خواهد.)

## نصب‌کننده چه می‌کند

| مورد | مقدار |
|---|---|
| مسیر نصب | `C:\Program Files\TanbalType` |
| نوع نصب | برای همهٔ کاربران (`ALLUSERS=1`) — به دسترسی ادمین نیاز دارد |
| شورت‌کات | منوی Start و میزکار |
| پیش‌نیاز | Microsoft .NET 8.0 Desktop Runtime (x64) — فقط اگر **هیچ** نسخهٔ 8.0.x روی سیستم نباشد |
| حذف برنامه | از Apps & features ویندوز |
| نصب نسخهٔ جدیدتر | نسخهٔ قدیمی خودکار حذف می‌شود (یک ردیف در Add/Remove می‌مانَد) |
| نصب نسخهٔ قدیمی‌تر | جلویش گرفته می‌شود |

نصب‌کننده عمداً برنامه را به استارت‌آپ ویندوز اضافه نمی‌کند؛ این کار از منوی
کلیک‌راستِ آیکن برنامه (گزینهٔ «اجرا در استارت‌آپ») انجام می‌شود و آن گزینه خودش
وجودِ شورت‌کات را در پوشهٔ Startup کاربر بررسی می‌کند. اگر نصب‌کننده هم جداگانه
چیزی اضافه می‌کرد، تیکِ آن منو با واقعیت نمی‌خواند.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `TanbalType.ism` | پروژهٔ InstallShield (نوع Basic MSI). در قالب XML ذخیره شده تا در git قابل‌خواندن و diff باشد؛ در IDE هم مثل حالت دودویی باز می‌شود. |
| `New-TanbalTypeIsm.ps1` | پروژهٔ بالا را از صفر می‌سازد. فقط وقتی لازم است که ساختار نصب‌کننده عوض شود. |
| `TanbalType .NET 8 Desktop Runtime (x64).prq` | پیش‌نیازِ .NET 8. نسخهٔ آمادهٔ InstallShield فقط دنبالِ دقیقاً 8.0.6 می‌گشت و روی سیستمی که 8.0.10 یا 8.0.28 داشت هم می‌گفت .NET 8 را نصب کنید؛ این نسخه هر 8.0.x را قبول می‌کند (برنامه خودش روی جدیدترین وصلهٔ 8.0 اجرا می‌شود). با اسکریپت بالا ساخته می‌شود. |
| `build-installer.bat` | publish + ساخت پروژه + بیلد. |

`payload/` و `TanbalType/` خروجی بیلد هستند و در git نادیده گرفته می‌شوند.

## نکته‌ها برای تغییرهای بعدی

**نسخه.** `<Version>` در `TanbalType/TanbalType.csproj` و `VERSION` در
`build-installer.bat` باید یکی باشند.

**UpgradeCode.** مقدار `{4C1F9E27-4A4D-4C8E-9D3E-1B7A6F2C5E80}` در
`New-TanbalTypeIsm.ps1` هرگز نباید عوض شود؛ همین است که ویندوز می‌فهمد نسخهٔ جدید
جایگزینِ نسخهٔ قبلیِ همین برنامه است. `ProductCode` برعکس، هر بار تازه ساخته می‌شود
و همین چیزی است که Windows Installer برای یک major upgrade انتظار دارد.

**زبان نصب‌کننده.** روی این سیستم فقط فایل‌های زبانِ انگلیسی (0409) نصب شده، پس
دیالوگ‌های نصب انگلیسی‌اند. برای فارسی‌کردنشان باید زبان مربوطه در خودِ
InstallShield نصب و بعد از `AddLanguage` استفاده شود.

**ویرایش دستی.** `TanbalType.ism` در مخزن هست، پس می‌توانید همان را در InstallShield
باز کنید و تغییر بدهید؛ لازم نیست اسکریپت را دوباره اجرا کنید. اگر اسکریپت را اجرا
کنید، فایل از صفر ساخته می‌شود و تغییرهای دستی از بین می‌رود.
